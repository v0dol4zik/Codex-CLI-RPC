# Security

Please do not publish Discord Client Secrets, Bot Tokens, or personal
configuration files in issues, pull requests, logs, or screenshots.

The Discord Application ID used by this project is not a Bot Token, but local
configuration should still stay outside the repository. If a Client Secret or
Bot Token is exposed, rotate it immediately in the relevant provider portal.

For a private vulnerability report, open a GitHub security advisory when the
repository is enabled for it. Otherwise contact the repository maintainer
privately instead of opening a public issue.
